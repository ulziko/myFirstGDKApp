1. `crates/shared`: Shared `serde` types (`SectionId`, `PortfolioData`, `ProjectEntry`, `ExperienceEntry`, `CertificationEntry`, `BuildLogEntry`, `ContactPayload`, `ApiError`) used by both the WASM frontend and Rust API functions.
2. `crates/frontend` (Bevy 3D -> `wasm32-unknown-unknown`):
   - Renders a sleek 3D scene (e.g., an interactive dark/grid spatial stage, floating data nodes/monoliths representing sections `00`–`08` and featured projects, subtle lighting, and a matrix/particle/grid backdrop with user-adjustable speed/density/opacity/reduced-motion controls).
